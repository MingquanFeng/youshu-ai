# AI记账助手 API 文档

## 1. 用户接口

## 微信登录

POST

    /api/user/login

请求：

``` json
{
"code":"微信code"
}
```

返回：

``` json
{
"token":"xxx"
}
```

------------------------------------------------------------------------

# 2. 图片上传

POST

    /api/bill/upload

参数：

multipart/form-data

字段：

    file

返回：

``` json
{
"image_id":"123"
}
```

------------------------------------------------------------------------

# 3. AI识别账单

POST

    /api/bill/recognize

请求：

``` json
{
"image_id":"123"
}
```

返回：

``` json
{
"amount":35.8,
"merchant":"星巴克",
"category":"餐饮",
"time":"2026-08-11",
"payment":"微信支付"
}
```

------------------------------------------------------------------------

# 4. 保存账单

POST

    /api/bill/save

请求：

``` json
{
"amount":35.8,
"category":"餐饮",
"merchant":"星巴克"
}
```

------------------------------------------------------------------------

# 5. 查询账单

GET

    /api/bill/list

参数：

    page
    size
    category
    date

------------------------------------------------------------------------

# 6. 消费分析

POST

    /api/analysis/monthly

返回：

``` json
{
"total":5230,
"top_category":"餐饮",
"advice":"减少外卖消费"
}
```

------------------------------------------------------------------------

# 7. API设计规范

统一返回：

``` json
{
"code":0,
"message":"success",
"data":{}
}
```

认证：

JWT Token

接口版本：

    /api/v1/
