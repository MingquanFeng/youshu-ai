# AI记账助手 PRD 文档

## 1. 产品概述

产品名称：

AI记账助手

定位：

AI原生个人记账应用。

核心价值：

让用户通过截图、拍照、自然语言快速完成记账。

------------------------------------------------------------------------

# 2. 用户画像

目标用户：

-   经常使用微信支付宝支付的人群
-   不愿手动输入账单的人群
-   希望了解消费结构的人群

------------------------------------------------------------------------

# 3. 产品功能

## 3.1 首页

目标：

快速进入AI记账。

页面：

-   今日消费金额
-   AI记账入口
-   最近账单

------------------------------------------------------------------------

## 3.2 AI记账

流程：

1.  用户上传图片
2.  系统进行OCR
3.  AI分析消费信息
4.  返回结构化结果
5.  用户确认保存

支持：

-   微信支付截图
-   支付宝截图
-   商品小票

------------------------------------------------------------------------

## 3.3 AI识别结果

展示：

-   金额
-   商户
-   分类
-   时间
-   支付方式

操作：

-   修改
-   确认保存

------------------------------------------------------------------------

## 3.4 账单列表

功能：

-   查看账单
-   日期筛选
-   分类筛选
-   编辑账单

------------------------------------------------------------------------

## 3.5 消费分析

展示：

-   月消费金额
-   分类占比
-   消费趋势
-   AI建议

示例：

"本月餐饮消费相比上月增长30%，建议控制外卖支出。"

------------------------------------------------------------------------

# 5. AI设计

## 图片识别Prompt

你是专业记账助手。

从消费图片中提取：

-   金额
-   商户
-   时间
-   支付方式
-   消费分类

返回JSON。

------------------------------------------------------------------------
