# AI记账助手 MVP 文档

## 1. 产品目标

验证核心价值：

> 用户上传一张支付截图，AI自动识别并生成账单。

MVP不追求完整财务系统，只验证 AI 自动记账流程。

------------------------------------------------------------------------

## 2. MVP范围

### P0 核心功能

  功能         说明
  ------------ ------------------
  微信登录     用户身份识别
  AI图片记账   上传截图自动识别
  账单保存     生成结构化账单
  账单列表     查看历史记录

### P1功能

  功能       说明
  ---------- ----------------
  账单编辑   修改AI识别结果
  消费统计   分类统计

暂不开发：

-   家庭账本
-   银行卡同步
-   理财功能
-   社交功能

------------------------------------------------------------------------

## 3. 用户流程

打开App → AI记账 → 上传支付截图 → AI识别 → 用户确认 → 保存账单

------------------------------------------------------------------------

## 9. 成功指标

-   AI识别准确率 ≥90%
-   用户确认率 ≥80%
-   单次记账耗时 \<10秒
