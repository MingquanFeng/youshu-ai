# AI记账助手系统架构设计

## 1. 系统目标

构建一个 AI 原生记账系统：

用户上传消费图片或输入自然语言，系统自动完成：

图片识别 → 信息抽取 → 分类 → 账单生成 → 消费分析。

# 3. 技术组件

## 客户端

-   UniApp
-   Vue3
-   TypeScript
-   Pinia

## 服务端

-   Python 3.12
-   FastAPI
-   SQLAlchemy
-   Pydantic

## AI层

视觉识别：

-   PaddleOCR
-   Qwen3-VL

文本分析：

-   DeepSeek-V3

本地推理：

-   Ollama

## 数据层

数据库：

-   PostgreSQL

缓存：

-   Redis

文件：

-   OSS/COS
